# Security policy

Please report a vulnerability in Forja privately through
[GitHub private vulnerability reporting](https://github.com/getnodalia/forja/security/advisories/new),
not in a public issue or pull request. Say which version you ran, on which platform, and how to
reproduce the problem. A small sample drawing helps, as long as it holds nothing private.

Nodalia maintains Forja and handles every report. Only the latest release receives security fixes.
